# 分阶段交给 Agent 的任务

## 建立档案

> 先读取教程，检查版本、源码适配和权限。定位我自己的微信账号数据目录，制作数据库与 WAL 副本。优先验证已有密钥，仅在缺钥且我授权的情况下捕获。所有原库只读。导入 DuckDB 后，报告最新消息、同步时间和逐库缺口；不要把部分成功说成全部完成。公网仓库只存源码。

## 处理语音

> 我授权把已提取的语音发送给我配置的 Gemini 项目转写。先做十条，核对发送者、会话、时间和消息标识，再处理其余待办。保留原件和独立转写表，报告缺音频、匹配冲突与失败，不能覆盖原消息。

## 使用桌面 Skill

> 使用 wechat-desktop Skill，找到我指定的联系人并打开聊天。你可以把微信切到前台。先核对近期上下文，确认是正确的人，然后发送我要求的消息。已有授权不需要重复确认；身份不明确或已有草稿时先报告。输入和发送之间看一遍截图，发送后验证，不重复发送。

真实收件人和内容在私有对话里提供，不保存在本文件。首次验证优先选择用户自己的联系人。

## 建立多端阅读

> 在档案已能查询后，搭建只读展示副本，用我自己的账号和域名。先验证 Web 登录、历史分页及服务端拒绝写入，再做 iOS/Android。使用自己的 App ID 与签名，不把数据库、密钥、密码、内网地址或私人截图提交到公开仓库。手机远程发送是单独项目，当前保持只读。
