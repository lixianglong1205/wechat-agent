# 配套源码状态

## 本次可以直接使用

`skills/wechat-desktop/` 是自包含的桌面操作 Skill：包含指令、安装与故障说明、Python 命令入口、Swift 截图和键盘源码。在自己的 Mac 上编译、授权后使用。不依赖作者的数据库、密钥、微信联系人或客户端服务。

## 后续一起核对并合入

完整档案、只读服务端和移动应用已在私有原型中运行，但当前公开提交不直接复制整个原型。下列工作需要在发布相应源码时完成；教程中对应命令不是本次仓库现成的命令。

| 模块 | 整理内容 |
| --- | --- |
| archive + query Skill | 删除默认账号和绝对路径；提供显式配置；保留页认证、WAL 校验、锁、metadata、转写恢复及测试 |
| privileged helper | 消除开发者固定路径和账号；按安装用户绑定；保留固定入口与 root 管理边界；单独审阅安装、更新和卸载 |
| reader | 提取 Tinode 导入、只读权限和主题；生成部署者自己的凭据；说明历史回填和缓存限制 |
| mobile | 参数化后端地址、应用名称、Bundle ID、Apple Team；移除开发者的 TestFlight 自动化和账号路径；保留可公开的构建步骤 |
| upstream | 固定 Tinode 源码版本并保留 Apache-2.0 许可；服务端使用 GPL-3.0 上游时保留其许可，不用本仓库 MIT 覆盖它 |
